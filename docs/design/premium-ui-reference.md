# 有償品質UIリファレンス

## 基準画像

- `docs/design/train-induction-premium-ui-reference.png`
- 生成日: 2026-05-15
- 目的: 3歳児向けの「絵本の世界」トップダウン電車誘導ゲームを、有償アプリとして成立する密度と質感へ引き上げるためのUI基準。

## 採用する要素

- 上部HUDは、クリーム色の丸みあるバーに戻るボタン、コース名、星の難易度をまとめる。
- 盤面は画面中央の主役として、白い太枠と影を持つ正方形寄りのボードにする。
- 残り穴数は、盤面とHUDの間に独立した丸い状態チップで表示する。
- 下部のレール候補は、実物のピース置き場に見えるクリーム色トレイと厚みのあるカードにする。
- 線路は上から見た梯子状の視認性を優先し、カードと盤面のどちらでも同じ見え方にする。

## 実装で調整する要素

- 画像内の文字はそのまま使わず、アクセシビリティとレスポンシブ対応のためHTMLテキストで組む。
- 3歳児向け操作を優先し、装飾よりもタップ領域、盤面余白、選択状態の明確さを優先する。
- 既存のゲームデータ、進行、判定ロジックは維持し、UIレイヤーを中心に更新する。
