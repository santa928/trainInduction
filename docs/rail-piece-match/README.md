# 候補と盤面のレールを統一（2026-10-24）

対象ブランチ: `fix/matching-rail-pieces`。比較元・公開版は `2899888`。

候補だけが独自SVGで、枕木5本・太い2色線・真上の視点だった。盤面は枕木6本の3Dモデルで、幅・材質・視点が違っていた。接続のデータは共通でも、見た目を照合しづらい状態だった。

候補も盤面の `railModel` をそのまま描画した画像に変更した。照明、色調、カメラの向きを共用し、画面サイズ変更に合わせて切り替える。ドラッグ中も同じ画像を使う。既存のWebGL描画処理を一時利用し、視点ごとの画像を再利用するため、候補ごとのWebGLキャンバスや描画ループは増やしていない。

ゲームルール・線路モデル・接続方向・速度・保存データ・依存パッケージは変更していない。

## 検証

- Node 22 / Docker: 単体・コンポーネント78件成功。型検査を含むビルド成功。既存の500kB超チャンク警告は残る。
- 新しいブラウザ回帰: 旧SVGでは候補画像が0件で失敗することを確認してから修正。Chromium/WebKitの2件成功。画像が空白でないこと、違う形の画像が重複しないこと、3視点の切替と再利用、キャンバス寸法の復元を実ブラウザで確認。
- 既存の操作回帰: Chromiumの返却/上書き/リサイズ/停止復帰、実タッチドラッグ/取消、WebGL喪失/復帰、WebKitの返却/上書き/リサイズ/停止復帰の4件成功。Chromium専用注入2件はWebKitでは明示skip。
- Chromiumの実タッチ入力相当: 12面目を5ピース配置→3画面サイズへ変更→実時間で駅到着。配置・時計・クリア状態は直接書き換えず、後半面の解放だけ旧保存fixtureを使用。画像を目視比較した。
- 実機iPhone/iPad、端末の性能、幼児による識別しやすさの受け入れ確認は未実施。
